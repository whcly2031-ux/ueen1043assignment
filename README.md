## 📌 Project Overview
This project is an automated data pipeline designed to analyze financial transactions. It handles the full data lifecycle: loading raw CSV data, performing rigorous cleaning, merging datasets to provide business context, and generating high-resolution visualizations to detect fraud patterns.

### Key Technical Implementations:
* **Object-Oriented Programming (OOP):** Uses a `TransactionAnalyzer` class with **Private Access Modifiers** (Encapsulation) to ensure data security and integrity.
* **Data Sanitization:** Cleans currency strings, handles missing values (NaN), removes duplicate IDs, and filters out system error logs.
* **Visual Analytics:** Generates 5 distinct insights using `matplotlib` at 500 DPI for professional reporting.
